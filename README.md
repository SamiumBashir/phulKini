# ফুল কিনি (Phul Kini) 🌸

> **“ভালোবাসা হোক ফুলের ভাষায়”**

**ফুল কিনি (Phul Kini)** হলো একটি আধুনিক, প্রিমিয়াম ও নান্দনিক বাংলাদেশি ফ্লোরাল ই-কমার্স ওয়েব অ্যাপ্লিকেশন।

---

## ✨ প্রধান বৈশিষ্ঠ্যসমূহ (Key Features)

- 🌹 **প্রিমিয়াম ফ্লোরাল ক্যাটালগ**: ডাচ গোলাপ, ওরিয়েন্টাল লিলি, টিউলিপ, সূর্যমুখী, অর্কিড ও লাক্সারি ব্লুম বক্স।
- ✨ **৮-ধাপের কাস্টম তোড়া বিল্ডার (“নিজের মতো করে তোড়া বানান”)**: পছন্দসই ফুল, স্টেম সংখ্যা, কালার প্যালেট, র‍্যাপিং স্টাইল, উপহার অ্যাড-অন ও ফ্রি গ্রিটিং কার্ড সহ লাইভ প্রাক্কলন।
- 🛒 **ইন্টারেক্টিভ শপিং কার্ট ও কুপন ইঞ্জিন**: `PHUL10`, `BOSONTO20`, `LOVE2026` সহ স্বয়ংক্রিয় ডিসকাউন্ট ও ফ্রি ডেলিভারি প্রগ্রেস বার।
- 🚚 **২-কলাম দ্রুত চেকআউট**: পূর্ণ নাম, ঠিকানা, ডেলিভারি শিডিউল ও বাংলাদেশি পেমেন্ট মেথড (বিকাশ bKash, নগদ Nagad, কার্ড, ক্যাশ অন ডেলিভারি)।
- 📍 **অর্ডার কনফার্মেশন ও লাইভ ডেলিভারি ট্র্যাকিং**: ৪-ধাপের লাইভ স্ট্যাটাস ট্র্যাকার ও ইনভয়েস রসিদ।
- 📍 **একীভূত যোগাযোগ ও আউটলেট ডিরেক্টরি**: বনানী, গুলশান ও ধানমন্ডি বুটিক আউটলেট, সরাসরি হটলাইন ও ফ্লোরিস্ট হোয়াটসঅ্যাপ চ্যাট।
- 📱 **সম্পূর্ণ রেসপন্সিভ মোবাইল অভিজ্ঞতা**: মোবাইল বটম নেভিগেশন বার, ফিল্টার স্লাইড-ইন ও ফাস্ট টাচ ইন্টারঅ্যাকশন।

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Google Fonts (`Hind Siliguri`, `Noto Sans Bengali`, `Plus Jakarta Sans`, `Inter`)
- **Animations**: Canvas Confetti & Tailwind Micro-transitions

## 🚀 লোকাল সেটআপ ও রান করার নিয়ম (Getting Started)

১. রিপোজিটরি ক্লোন বা ডাউনলোড করুন:
```bash
git clone <repository-url>
cd "Phul Kini"
```

২. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

৩. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
ব্রাউজারে ওপেন করুন: `http://localhost:3000`

৪. প্রোডাকশন বিল্ড তৈরি করুন:
```bash
npm run build
npm start
```
